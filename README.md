# 사장님커뮤니티 GitHub Pages 배포 가이드

이 폴더 안의 3개 페이지 + assets 폴더를 그대로 GitHub 저장소에 올리면 외부(카카오 임직원이 아닌 사람 포함) 누구나 볼 수 있는 공개 페이지가 됩니다.

## 폴더 구성
- `index.html` — 5기 참가자 FAQ (첫 진입 페이지)
- `curriculum.html` — 5기 커리큘럼 상세
- `results4.html` — 4기 성과 및 개선 VOC 보고서
- `assets/` — 각 페이지에서 쓰는 이미지 5개

세 페이지는 서로 상단 네비게이션/하단 footer 링크로 연결되어 있습니다.

## 배포 순서 (5분 내 완료)

1. **GitHub 계정 준비** — 이미 있으면 로그인, 없으면 github.com에서 무료 가입.
2. **새 저장소(repository) 생성**
   - github.com 우측 상단 `+` → `New repository`
   - Repository name 예: `ceocommunity5-faq` (원하는 이름으로 가능)
   - `Public`으로 설정 (Pages 무료 배포는 Public 저장소 기준)
   - `Create repository` 클릭
3. **파일 업로드**
   - 생성된 저장소 페이지에서 `Add file` → `Upload files`
   - 이 폴더 안의 `index.html`, `curriculum.html`, `results4.html`, `assets` 폴더를 통째로 드래그해서 올리기
     (assets 폴더째로 끌어다 놓으면 GitHub가 하위 파일까지 그대로 업로드합니다)
   - 하단 `Commit changes` 클릭
4. **GitHub Pages 활성화**
   - 저장소 상단 `Settings` 탭 → 좌측 메뉴 `Pages`
   - `Build and deployment` → `Source`를 `Deploy from a branch`로 선택
   - `Branch`는 `main` (또는 `master`), 폴더는 `/ (root)` 선택 후 `Save`
5. **1~2분 후 주소 확인**
   - 같은 Pages 설정 화면 상단에 `https://<본인깃허브아이디>.github.io/<저장소이름>/` 형태의 주소가 표시됩니다.
   - 이 주소가 바로 외부에 공개해도 되는 링크입니다. (`/index.html`을 붙이지 않아도 FAQ 페이지로 들어갑니다)

## 이후 내용을 수정하고 싶을 때
- 저장소 안에서 해당 `.html` 파일을 열고 GitHub의 연필(✏️) 아이콘으로 바로 수정 → `Commit changes` 하면 1분 내 반영됩니다.
- 저는 로컬 파일을 다시 만들어드릴 수 있으니, 내용 변경이 필요하면 말씀해주세요. 그 파일로 위 3번(업로드) 과정만 다시 반복하면 됩니다.

## 23차 수정 (검색창 클릭 영역 + 주차 검색)

### 1) 검색창 클릭이 되다 안 되다 하던 문제
원인은 히어로 하단의 장식용 곡선이었다. `.hero::after`(`position:absolute; bottom:-40px; height:80px; background:var(--bg)`)는 `.hero::before`와 달리 `pointer-events:none`이 없었고, `.searchbox`는 `margin:-30px auto 28px`로 그 곡선 위로 끌어올려져 있으면서 `z-index`가 없었다. 그래서 입력창 위쪽 띠 영역에서는 클릭이 곡선에 먹혔다 — 아래쪽을 누르면 되고 위쪽을 누르면 안 되는 증상이 여기서 나왔다.

조치는 세 가지다. `.hero::after`에 `pointer-events:none`을 넣어 장식이 입력을 가로채지 못하게 했고, `.searchbox`에 `z-index:3`을 주어 히어로 위로 확실히 올렸다. 그리고 클릭 영역 자체를 넓혔다 — 입력창은 `min-height:62px`(모바일 56px)에 상하 패딩 20px(모바일 17px)로 키우고, `.searchbox`에 `padding:8px`과 `cursor:text`를 주어 입력창 주변 여백까지 누를 수 있게 한 뒤, `#searchBox`의 `mousedown`/`touchend`에서 입력창이 아닌 곳을 눌러도 `searchInput.focus()`가 걸리도록 했다. 아이콘 위치는 늘어난 패딩에 맞춰 `left:20px → 28px`(모바일 16px → 24px)로 옮겼다. iOS 확대 방지를 위해 입력 `font-size:16px`은 그대로 유지했다.

### 2) 「4주차」「5주차」 검색
먼저 사실관계를 바로잡는다. **지워진 정보는 없다.** `주차`는 원래 `curriculum` 주제의 라우팅 키가 아니었다. KB는 `회차`로만 키가 잡혀 있었고(`'2회차'`~`'5회차'`), 페이지 본문에 있던 `주차`는 「2주차 튜토리얼 범위」 같은 설명 문구와 `event` 주제의 **주차(parking)** facts 키뿐이었다. 그래서 「2주차」는 FAQ 본문 텍스트 검색에 우연히 걸렸고 「4주차」·「5주차」는 어디에도 걸리지 않았다. 되돌린 것이 아니라 이제 제대로 넣었다.
